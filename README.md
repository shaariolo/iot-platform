# IoT Platform — Real-Time Telemetry Data Platform

Real-time платформа обработки IoT-телеметрии с обогащением погодными данными и SQL-аналитикой поверх Data Lake.

## Стек

- Apache Kafka (KRaft)
- Spark Structured Streaming
- Delta Lake
- MinIO (S3)
- Trino
- Apache Airflow
- Soda Core
